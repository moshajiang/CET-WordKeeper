# CET WordKeeper

真题驱动的四六级学习桌面软件。阅读时查词、保存语境与批注，再把需要掌握的内容做成练习卡，按计划复习。

**当前发行版：v0.3.4 · Windows x64。** 内置真题、查词、资料整理和复习可离线使用；AI 功能需要自行配置服务，版本检查需要联网。

## 下载与开始使用

- [GitHub 发布页](https://github.com/moshajiang/CET-WordKeeper/releases/tag/v0.3.4)
- [码云发布页](https://gitee.com/moyunyi/cet-word-keeper/releases/tag/v0.3.4)

| 文件 | 用途 |
| --- | --- |
| `CET-WordKeeper-0.3.4-setup.exe` | 安装版，推荐日常使用，支持应用内下载更新和安装 |
| `CET-WordKeeper-0.3.4-portable.exe` | 单文件便携版，双击运行；更新时从发布页下载新文件 |
| `latest.yml`、`CET-WordKeeper-0.3.4-setup.exe.blockmap` | 自动更新配套文件，无需手动运行 |

升级前可在“设置 → 备份到…”保存学习库。安装版沿用原应用身份与用户数据目录；升级不会主动清空学习记录。便携版也使用用户数据目录，不应把程序文件当作学习数据备份。

建议第一次按以下顺序使用：

1. **真题库**选一套试卷，打开后先用“练题”模式作答。
2. 单击英文查词，双击把需要掌握的词加入**生词本**；划选表达可收藏短语或保存此处词义。
3. 交卷后核对答案，切到“精读”看逐句译文，用“复盘”整理错因和笔记。
4. 从笔记、短语或语境义**制作练习卡**，核对候选内容后保存，按需加入复习。
5. 在**复习**页完成到期内容；用设置中的每日额度和每轮时长控制学习量。

## 首页与继续学习

“今日”页显示待复习量、逾期积压和最近访问的材料。点击“继续学习”返回上次篇章，也可以直接继续未交卷试卷、作文或翻译草稿。首页的单词、知识点和练习卡提醒分别进入对应复习队列，彼此不会混为同一条进度。

**夜间阅读：** 在“设置 → 外观”点击“切换为夜间模式”，再次点击可回到浅色；重启后保留选择。

## 真题阅读与做题

**入口：真题库 → 选择考次 → 打开试卷。** 内置 78 套 CET4/CET6 材料，包含写作、选词填空、长篇阅读、仔细阅读和翻译，不含听力。

1. 用篇章栏切换材料；客观题直接选择选项，选词填空按空号选择给定词库字母。
2. “练题”适合独立作答，“精读”使用逐句对照，“复盘”查看解析并整理错因。切换模式不会删除作答。
3. 阅读设置可调整译文显示、单/双栏、字号；页面记住相应试卷的设置和阅读位置。
4. 点击“交卷核对”后查看客观题对照和得分，再展开解析、译文、范文或参考译文。
5. 需要重新练习时使用“重做本套”，按页面确认清除该套当前作答后重来。未交卷草稿与已交卷记录按真实状态分别恢复。

内置答案、解析与译文随库提供，无需 API Key。部分参考内容由 AI 预生成并经独立核对，仍可能有误，应结合题面审阅；不是官方解析。自导入材料缺少答案时，按需补全需要 AI 配置。

## 离线查词与生词本

**查词：** 单击英文单词，查看音标、释义、考纲标签与真题词频。词形还原将 `went → go`、`intervening → intervene` 等关联到原形；相应统计按词条归并。

**收藏：** 在原文双击单词加入生词本，保存当前语境和篇章出处；“难词预扫”可查看当前篇章的难词并批量加入。

**整理：** 侧栏“生词本”可搜索、排序、查看真实出处、写备注，以及调整学习/掌握状态。打开词条详情可回看多个出处。同词的不同语境解释请使用下方“语境义”，避免覆盖词典释义。

**复习：** “复习 → 生词复习”中先回忆再翻面，按实际记忆选择评分；安排和学习记录保存在本机。掌握状态与单个语境卡的进度相互独立。

## 划选讲解与页面助手

**需要 AI 配置。** 页面右下角打开助手，或按 `Ctrl+J` 呼出。

1. 在阅读器划选英文，点击“就地讲解”、翻译或语法分析。讲解会在原文附近显示，并高亮真实划选位置。
2. 可围绕当前材料提问，例如“标出这道题的原文依据”“定位第 46 题”“切到下一篇”“显示逐句译文”。支持的页面操作由程序校验后执行。
3. 多处证据可逐一查看和定位；用“撤销上次页面操作”恢复最近一次阅读器布局、篇章或临时高亮变化。
4. 需要保留讲解时选择“存入知识库”，检查可编辑草稿再保存。
5. 可停止生成；切换篇章或上下文后旧结果不会自动操作新页面，历史对话也不会重放页面动作。

引用卡显示实际加载的原文或资料，便于核对，不代表模型每个结论都已被证明。详见 [页面助手说明](docs/AI-PAGE-ASSISTANT.md)。

## 永久批注与知识库笔记

**批注入口：阅读器 → 划选原文 → 保存划选批注。** 选择颜色、写备注并保存；在“我的批注”中打开、定位或删除。正常重启后恢复已保存内容；若原文改变，保留批注但不猜测新的高亮位置。

**知识库入口：侧栏 → 知识库。** 内置 36 条题型、语法、阅读与表达资料，例句和自测用于教学，不是真题或押题。

1. 搜索标题、正文或标签，结合来源、分类与标签筛选，点击条目阅读全文。
2. 内置资料只读，需要修改时先“复制为我的笔记”；也可直接新建个人资料。
3. 编辑标题、正文、分类与标签后保存。原文讲解整理的笔记带真实出处，可返回对应篇章并高亮。
4. 个人笔记可移入回收站或恢复；来源变化/删除不会自动删除已保存正文。
5. 保存需要的修改后再切换；未保存内容会提示处理。

详见 [知识库](docs/KNOWLEDGE-LIBRARY.md)、[学习联动](docs/STUDY-EXPERIENCE.md)。

## 短语收藏与熟词生义

**收藏短语：** 在真题完整划选 2～12 个英文词 → “收藏短语” → 填写此处释义、备注和标签 → 保存。

**保存此处词义：** 单击单词后选择对应入口，或完整划选一个英文单词 → “保存此处词义” → 写下当前语境含义 → 保存。原形和变形可关联查看，但每处保留自己的解释、上下文与出现位置。

**管理：** 侧栏“短语收藏”“语境义”支持搜索、标签筛选、编辑、回收恢复和“返回原文并定位”。同一位置重复收藏保留原释义；相同表达在别处可以独立保存。

**AI 此处释义：** 在收藏窗口或详情点击“AI 建议此处释义”，查看 1～3 个候选及真实原文依据。明确“采用到释义草稿”后仍可修改，再手动保存；需要时可保留文字改为手动编辑。候选不自动入库，支持停止；保存后的 AI 辅助来源和人工改写状态可查看。

AI 请求只使用此处表达、保存上下文及出处，不会自动发送其他收藏或当前手写草稿；语义是否恰当仍需核对。[短语说明](docs/PHRASES.md) · [语境义说明](docs/CONTEXTUAL-SENSES.md) · [AI 释义说明](docs/AI-CONTEXT-MEANING.md)。

## 独立练习卡与六类题型

**入口：知识库/短语/语境义详情 → 制作练习卡，或侧栏 → 练习卡。**

1. 选择来源，手动新建、把已有自测整理为候选，或主动让 AI 生成候选。
2. 核对题目、选项、答案、解析和标签，取消不需要的候选，再“保存勾选卡片”。勾选“保存后加入复习”才入队。
3. 在管理页按题型、标签、来源或状态筛选；可编辑、入队、暂停、继续、移出、归档和恢复。归档恢复默认暂停，避免突然增加负担。
4. “复习 → 练习卡”先作答后核对。问答与翻译由你自评；判断/选择按保存答案对照；拼写/填空检查参考表达。
5. 查看最近作答及当时题目、答案和来源快照。改题/改答案会重新学习，已有历史保留；来源后来修改或回收不会重写旧卡。

| 题型 | 使用方式 |
| --- | --- |
| 问答 | 回忆规则、释义或依据，翻面后自行核对 |
| 翻译 | 独立写/想译文，翻面后对照参考内容，不自动批改 |
| 判断 | 先选正确/错误，再看解析并如实评分 |
| 选择 | 先选字母，再核对答案和选项依据 |
| 拼写 | 从收藏的此处释义回忆原文表达，保持原词形 |
| 原句填空 | 填写唯一“【填空】”目标；其他同词提示可能被遮挡 |

拼写核对忽略大小写、兼容字符与多余空白，不把原形、同义词或近似拼写当成正确。错误输入只能选择未想起；不会凭空把错误记为成功。[练习卡](docs/PRACTICE-CARDS.md) · [拼写与填空](docs/TYPED-PRACTICE.md)。

## 复习节奏与可选 FSRS

**设置学习量：** “设置 → 复习节奏”分别设置每日新词/新卡额度、每轮数量与目标时长。已学到期内容优先，可暂缓新内容或提前结束，未完成项保留原安排。不会因为重启、重复点击或首次遗忘而重复计新增额度。

**看安排：** 翻面后查看各评分对应的预计间隔，再按实际回忆评分。默认使用本软件的简化间隔规则；词汇、知识点与独立卡片的队列分开管理。

**本地对照：** 在设置的调度评估中主动运行 FSRS 只读对照，查看符合条件的历史；对照结果不会改写实际安排。

**新卡 FSRS 试用：** 在练习卡详情选择从未作答的新卡，先预览、确认后启用；最多 10 张。启用/退出前自动备份，使用“没想起/费力想起/正常想起/很轻松”四档。退出后保留全部作答并接续原调度，不能用旧备份覆盖新作答。不会自动迁移所有旧单词或训练个人参数。

实际记忆效果与负担仍需使用观察。[复习量](docs/REVIEW-PACING.md) · [调度对照](docs/SCHEDULER-EVALUATION.md) · [FSRS 试用](docs/FSRS-TRIAL.md)。

## 对照背诵

**入口：侧栏“对照背诵”选试卷，或阅读器顶部“对照背诵”。** 选择篇章和先显示中文/英文，点“下一句”逐句呈现；点击一句切换语言。“全文显示”展开全部，“重来”重新开始，“返回做题”回到同一材料。无预置译文的材料会提示，背诵入口不会自动付费生成内容。

## 作文翻译与逐处修改

**入口：真题 → 写作/翻译篇章。**

1. 在作答框独立写作文或译文，草稿自动保存；首页也能返回未完成草稿。
2. 点击“查看范文/查看参考译文”阅读预置参考内容，离线可用。
3. 配置 AI 后可主动批改，查看参考评分、亮点、问题与改写建议；评分不是官方成绩。
4. 引文能唯一对应当前草稿且提供替换内容时，可逐处采纳并撤销最近一次；引文不唯一或草稿已变时手动修改。
5. 修改后原评分不再代表新稿，需要时重新批改；薄弱点可整理为笔记。

作文词数是估计值，批改质量取决于所选服务。当前草稿作为批改/针对草稿提问的内容发送给所配 AI；普通离线参考阅读不发送。

## 错题复盘与知识点自测

**错题复盘：** 在题目解析下记录可能错因、原文证据和改进方法，关联知识库资料后保存。复习页的错题复盘可返回对应篇章并聚焦题目。AI 错因建议只填入待确认表单，核对后保存，不把模型猜测当成已知事实。

**知识点自测：** 打开知识条目，先独立回答已有自测，再展开答案和依据；无预置自测时可做规则复述和造句。可加入知识点复习，在复习页按不会/模糊/会用评分；也可主动请求一道原创 AI 迁移练习，先答后看答案。

知识点复习与独立卡片分开；要把自测变成可编辑的长期题目，使用“制作练习卡”。

## 导出备份恢复与导入真题

| 操作 | 入口和步骤 | 结果与边界 |
| --- | --- | --- |
| 生词 Anki 导出 | 生词本 → 先筛选 → 导出当前结果到 Anki → 选择保存位置 | 将当前结果中的词与出处用于外部复习 |
| 收藏/卡片导出 | 短语、语境义或练习卡页先筛选 → 选 JSON/Anki → 预览数量 → 保存 | 保留原文与出处；卡片 JSON 可选全部历史及调度状态 |
| 完整备份 | 设置 → 备份到… → 选择位置 | 保存实际学习数据库；用于完整恢复 |
| 恢复备份 | 设置 → 选择备份 → 核对预览 → 确认恢复并重启 | 恢复到所选备份状态，先检查文件并留存恢复前数据 |
| 导入真题 | 设置 → 导入 → 选择符合格式的 JSON | 重复考次拒绝，不静默覆盖已有材料 |

**Anki 收藏/卡片文件：** 首次建立 ID、Front、Back 三字段笔记类型，ID 放第一位；正面模板 `{{Front}}`，背面 `{{FrontSide}}<hr>{{Back}}`。导入文本时映射前三字段和标签列，启用 HTML 并检查预览。同一笔记类型内保留 ID 识别重复，六题型按普通正反面卡导入，不迁移本软件的学习进度或自动输入核对。

**JSON 资料档案不能直接恢复数据库**，也不是完整备份；目前没有该档案的导入功能。具体范围见 [导出说明](docs/LEARNING-EXPORT.md)。

学习库默认位于 Windows `%APPDATA%\cet-wordkeeper\keeper.db`。不要删除它来解决一般问题；复制数据库前先关闭应用，优先使用界面备份/恢复。更新偏好等本机界面设置与数据库备份分开。

完整数据库备份包含 AI 配置和 Key，应妥善保管，不要作为普通学习资料公开分享。

自定义真题 JSON 示例：

将示例中的级别、年月和套号改为库中尚未存在的组合，再填写自己的材料。

```json
{
  "level": "CET4", "year": 2026, "month": 6, "set_no": 1,
  "passages": [{
    "section": "reading", "seq": 1, "content": "Your reading passage...",
    "translation": "可选参考译文",
    "questions": [{"stem": "46. What is the passage about?", "options": ["A) Reading", "B) Travel", "C) Health", "D) Work"], "answer": "A", "analysis": "可选解析"}]
  }]
}
```

## 自动检查更新与提醒

**入口：设置 → 版本更新。** 默认开启；安装版启动约 15 秒后检查，之后约每 6 小时检查一次，重启会保留检查间隔。首选 GitHub 或码云失败时尝试另一个来源。

发现新版本后在软件内跨页提醒。可“稍后提醒”24 小时或“跳过此版本”；新版本仍会提示。自动检查只取版本信息，不自动下载或重启。安装版明确点击下载，完成后再“安装并重启”；正常退出不自动安装。便携版打开实际检查来源的发布页。

旧 v0.3.3 用户先使用原设置页的手动更新或从发布页下载 v0.3.4，安装 v0.3.4 后即可获得新的启动检测机制。关闭软件后不注册额外后台服务。[详细说明](docs/AUTOMATIC-UPDATES.md)。

## AI 配置

**入口：设置。** 填写 OpenAI 兼容 API 地址（通常到 `/v1`）、你自己的 Key 和模型名称，保存并“测试连接”。使用哪些服务和模型由你决定，费用遵循服务商规则。

| 无需 AI/网络的主要功能 | 主动使用 AI 时才请求 |
| --- | --- |
| 内置真题阅读与核对、查词、生词本、预置解析/译文、背诵、知识库、手写收藏/制卡、已有复习、备份与导出 | 划选讲解/翻译/语法、页面助手、作文/翻译批改、候选练习卡、此处释义建议、自导入缺失答案生成 |

需要时可停止生成。候选释义、笔记和卡片均需审阅保存；不要直接把模型答案当成唯一依据。Key 保存在本机设置中，不应写进仓库或截图分享。

## 移动复习演示

仓库提供独立移动 Web 演示：六题型、本地 IndexedDB、待确认/冲突示例和演示副本导出。**它尚未连接桌面真实学习库，未提供正式配对、签名包导入或同步，也未作为手机端发行。** 桌面安装包不含移动站点。

从源码运行 `npm run dev:mobile`，在本机打开 `http://127.0.0.1:5174/`；`npm run build:mobile` 输出到 `dist-mobile/`。已打开页面可离线记录，离线重开页面/PWA 壳及手机实机交付仍待后续开发。[使用与截图](docs/MOBILE-REVIEW-PROTOTYPE.md) · [后续设计](docs/MOBILE-REVIEW-DESIGN.md)。

## 常见问题

**找不到新功能？** 请核对设置页版本为 v0.3.4。源码更新不会自动改变旧安装程序，旧版可手动检查或下载新安装包。

**没有弹出更新提醒？** 在设置检查自动开关与上次/下次时间；已稍后或跳过的版本不会重复提醒，也可能当前就是最新正式版。网络失败会记录错误并退避，可手动重试或换源。

**AI 不可用？** 检查地址、Key、模型和服务额度，再测试连接。未配置不影响离线主流程。

**收藏改了，旧卡为什么没变？** 卡片保留制作时的答案与出处快照。需要修改请进入卡片管理；已保存历史不会被改写。

**换电脑或误操作后怎样恢复？** 使用设置的备份/恢复；恢复所选备份会回到当时的数据状态。JSON 内容导出不能替代数据库备份。

**安装后数据是否保留？** 软件沿用原用户数据目录，并做增量迁移；仍建议升级前备份。不要手动覆盖正在运行的数据库。

**能在手机同步真实进度吗？** 暂时不能，目前仅有独立演示原型。
