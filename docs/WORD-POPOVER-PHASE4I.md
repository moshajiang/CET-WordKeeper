# 查词气泡与收藏出处：第四批 4I

日期：2026-10-19，源码版本保持 0.3.1。

## 已确认问题与修复

查词请求缺少返回身份，较早查询可以覆盖新词，并使显示的词与保存的原句不一致。现在每次查询捕获考次、篇章、加载代次及查询序号，仅当前可见气泡采用返回。关闭、切篇、换卷、离页和卸载使旧请求失效；失败显示原因并允许在同一原句上下文重新查询。选择复制和点击标点不再留下旧气泡。

收藏以前直接修改当前气泡的 inBook，双击另一个词的旧请求返回可能误标新气泡。现在收藏动作在发送前捕获原句/篇章，返回后只在原界面反馈；已发送动作仍正常提交到原出处。按词形的在途锁防止同词收藏/移除交错，词形映射途中就绪也保留互斥。修改成功后重新读取实际词表及当前气泡的出处，不凭旧返回的 status 覆盖新状态；旧词表返回不覆盖新快照。保存失败保留原状态并释放锁；保存成功但读取失败明确区分，允许重新查词。

划选菜单的延迟回调也校验页面和篇章身份；提示计时器不会由上一条消息清空新消息。

后端原来按 word + sentence 去重，相同句子在两个篇章的第二条出处被跳过。改为 word + passage_id + sentence，NULL 出处也独立幂等；同篇重复收藏继续跳过写盘。新增出处不改变已有单词的掌握状态、笔记、复习调度或历史记录。入口检查词/原句类型和篇章 ID，保留词典 b.c./i.e./p.m. 三个点号缩写的收藏兼容性，有出处时必须存在对应篇章，避免形成新的孤立引用；不要求原句是正文子串，保持对照句和已填空句子的收藏能力。

## 数据与行为边界

不新增 schema，不重建、删除或猜测旧 word_hit 记录。旧版已漏存的出处无法凭现有数据还原，再次收藏时可以追加。无原句的难词预扫快速收藏继续使用 NULL 出处，不伪造句子或篇章。收藏写入仍使用既有事务/原子持久化，写盘失败整体回退；真实用户数据、分发种子和安装程序不作为测试对象。
