# 拼写与原句填空

2026-10-26，P3 第三批，开发基线 `f2a6eef`。短语和语境义新增两种可编辑练习卡：根据此处释义拼写原文表达，以及在原文上下文中填写指定目标。当前为源码交付，尚未制作新安装包。

## 使用方式

1. 在“短语收藏”或“语境义”选择一条记录，将“练习方式”改为“拼写”或“原句填空”，点击制作练习卡。默认仍为释义问答。
2. 先审阅候选的题面、参考答案、解析和标签，可以编辑后选择保存。保存时单独决定是否加入复习，制作候选不会自动入库或消耗额度。没有 AI 配置也能完成整个流程。
3. 拼写候选显示此处释义、词数及字符数提示，要求填写原文词形。原句填空只保留一个 **【填空】**，同一表达的其他出现位置用 **【同词遮挡】** 隐去；语境义还遮挡字典确认的同词形变化，避免从相邻句直接抄答案。
4. 复习时先输入表达，点击“核对拼写”或按回车核对。空输入回车不翻面；没想起时可明确点“没想起，查看答案”，随后如实评分。作答前隐藏答案、解析、来源快照和可能透露词形的来源标题。
5. 核对后锁定本次输入，显示参考答案与原文依据。核对本身只读，不计一次作答、不标记完成、不消耗新卡额度；点击评分后才保存并计算下次时间。
6. 与参考拼写不一致时，原三档只能选“不会”，FSRS 四档只能选“没想起”。正确时再按实际回忆难度自评。主进程重新计算对照，前端不能伪造成功结果。旧选择/判断题与主观自评规则保留。
7. 管理详情可查看输入、拼写对照及当时的参考答案；修改题目或答案会重新学习，已有作答记录保留。暂停、归档、每日额度、每轮上限、提前结束和新卡 FSRS 试用继续生效。

卡片编辑器也可手动选择这两类题。参考答案应是 1 至 12 个英文词组成的表达，最长 240 字符；填空题面必须且只能包含一个【填空】标记。AI 通用出题仍沿用原有四类提示，本批不自动请求模型改写原文。

## 核对规则与边界

固定规则版本 `typed-answer:v1`：规范化 Unicode 兼容字符、统一弯撇号、忽略大小写、首尾空白和连续空白差异，再比较完整表达。不会把 set 当成 sets，不做词形还原、同义词推断或模糊拼写匹配，不删除句点或连字符。

这是对**当前卡片参考拼写**的核对，不判断所有同义表达是否正确，也不自动评估句法能力。若希望练习其他答案，应先审阅修改卡片；目标依然是一张卡对应一个可核对的表达。输入保存沿用卡片规则去除首尾空白，保留原大小写与内部空白；规范化比较值另行保存。

自动生成会去掉划选引文边缘的引号、括号和句末标点，保留内部拼写。提示中直接写出的目标也会遮挡，但用户仍需审阅题面是否有额外答案线索。旧收藏若没有可靠上下文偏移，拒绝自动制作填空，避免随意挖错位置；仍可制作释义拼写或手动审阅编题。

## 实现与数据

- `electron/practice-exercises.cjs`：两类题型校验、只读候选构建、目标与重复线索遮挡、参考拼写比较、版本化比较记录。按原始目标偏移挖空，重叠短语也优先保留被选中的目标。
- `practice:exerciseDraft` 读取已保存的短语/语境义，返回候选及来源摘要；没有写库或网络请求。保存时沿用原批次事务、操作身份和来源变化检查。
- `practice:check` 校验卡片版本、题型和输入，只返回核对结果。输入期间卡片被修改时拒绝陈旧核对，页面保留输入并提示重新加载。
- `practice_answer_check` 是新增增量表，以评分操作身份为主键，保存规则版本、当时规范化参考答案、规范化输入和结果。原 `practice_attempt` 继续保存卡片快照、作答、自评分、正确标识与到期；基础备份必需 SCHEMA 不变。
- 实际评分在同一事务保存核对记录、作答历史、卡片状态、调度审计/FSRS 状态与每日首次身份。SQL 或写盘失败整体回滚，相同成功请求重放返回已保存的比较结果，不重算新版本卡片或重复评分。
- 卡片类型扩展为六种，原四类和已保存卡片不自动转换。来源仍是原来的 phrase:/sense: 稳定身份；卡片编辑后重学，旧比较版本与快照保留。
- `PracticeCardReview.vue` 明确按翻面状态显示答案，核对过程中禁用重复提交，正确/失败的比较在换卡和结束本轮时清空。内部规则版本存于历史数据，日常界面使用“按参考拼写核对”的说明。
