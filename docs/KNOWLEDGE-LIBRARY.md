# 知识库改进

功能已包含在 v0.3.3 安装包中，并已发布至 GitHub 与码云 Releases。

## 使用方法

- 知识库采用目录与正文双栏展示，内置条目可阅读全文。
- 可以搜索标题、完整正文与标签，按来源、分类、标签组合筛选。正文命中时列表摘要会显示附近内容。
- 我的笔记支持创建、编辑、复制和删除；分类包括基础知识、真题笔记、我的薄弱点、未分类。标签使用逗号分隔，最多 12 个。
- 内置资料保持只读，可以复制为自己的笔记后修改。
- 原文旁的讲解窗口新增“存入知识库”：先进入可编辑草稿，检查标题、解释、分类和标签后点击保存。未点击保存的草稿不会写入资料库。
- 真题笔记展示来源套题、篇章及引文。点击“返回原文并高亮”打开对应篇章、恢复高亮并显示已保存的笔记，不调用模型。重复引文保留原有 occurrence 身份。
- 来源材料已移除或引用无法匹配时明确报错，不跳到猜测的位置，保存的笔记正文仍然可读、可编辑。
- 编辑后的未保存内容在切换条目、取消或离开页面时有放弃提示；删除需要在页面内再次确认。

## 实现与兼容性

- `electron/knowledge.cjs`：知识库服务、校验、来源解析和增量迁移。
- `kb_entry` 新增 `category`、`tags`（JSON）、`updated_at`、`origin`、`anchor`（JSON）。旧条目的标题、正文、ID 和创建时间保留，缺少分类的条目显示“未分类”。
- 原始 `SCHEMA` 的必需字段集合不变，旧版数据库备份仍可通过检查；在启动迁移中补列，不重建分发数据库。
- 保存、编辑和删除均复用主进程的 `persistTransaction`，写盘失败恢复内存快照。编辑携带更新时间，拒绝覆盖已更新的条目。
- 新增 `kb:search/get/save/source` 与对应 preload API；保留 `kb:list/add/remove` 兼容接口。
- 内置条目使用标题哈希作为稳定 key，用户条目使用 `user:<id>`。来源由主进程查验真实套题和篇章，并通过现有引文定位器规范化空白与检查重复位置。
- `useKnowledgeDraft.js` 只存放当前进程中的待审阅草稿；应用关闭前需要保存需要保留的内容。
- 传输笔记前在渲染层移除嵌套 Vue 代理，避免 contextBridge 在进入 preload 前拒绝来源对象。
- 正文复用现有安全 Markdown 渲染器；HTML 作为文本展示。

本轮完成资料管理与阅读器笔记闭环；AI 自动检索仍沿用已有关键词方案，尚未加入语义检索、引用来源卡片、知识点练习或自动合并同类笔记。

## 验证

```powershell
node node_modules/vite/bin/vite.js build
npm run test:knowledge
```

数据回归 11 项：旧库迁移幂等、旧备份兼容、内置只读、长正文检索、分类标签、编辑版本检查、输入边界、保存与删除失败回滚、真实来源与重复句身份、来源移除/变更、重启保留和定向删除。

真实 Electron 界面 16 项：全文阅读、复制内置资料、创建与编辑、分类搜索、Markdown 安全、删除取消与确认、AI 草稿审阅、保存嵌套来源、返回篇章与第二处重复引文、不重复调用模型和重新打开笔记。

界面测试使用独立临时数据库与本地模型响应，不访问真实用户资料或付费模型。可用 `KEEPER_KNOWLEDGE_ARTIFACTS` 指定截图目录。本轮只运行知识库相关检查与构建。
