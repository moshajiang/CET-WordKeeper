# AI 页面助手

2026-10-22。基于 v0.3.2，保留现有 Vue/Electron、OpenAI 兼容接口和本地学习数据库。功能已包含在 v0.3.3 安装包中，并已发布至 GitHub 与码云 Releases。

## 使用方式

- 每个页面右下角的「AI 助手」或 `Ctrl+J` 打开助手，支持展开宽面板、收起、停止生成和清空对话。输入法确认键不会发送，`Enter` 发送，`Shift+Enter` 换行。
- 阅读器划选英文，点「就地讲解」，原文保持高亮，讲解在附近浮出。原有整句翻译、语法分析也在原文旁显示。
- 可以直接说「高亮这篇文章的主旨句，并在旁边解释」「切换为左右布局」「定位到第 46 题」。模型返回有效操作后，软件执行并报告结果。
- 多个高亮支持上/下一处；收起卡片仍保留标注，点击高亮或「查看讲解」可以重开。「继续追问」带入对应引文。
- 可以要求打开真题库、生词本、复习、知识库、设置、今日或背诵页。从阅读器打开背诵时保留当前篇章。
- 切篇、切卷、离开阅读器会取消原材料的待处理操作并清除临时标注。对话回答会保存，重新打开时不会重放历史操作。

## 首版操作范围

| type | 参数 | 效果 |
| --- | --- | --- |
| highlight | passageId, quote, explanation, title?, occurrence? | 在真实原文中高亮，并展示附近讲解 |
| navigate_passage | passageId | 切换当前套题中的篇章 |
| focus_question | questionId | 切换到题目所属篇章，滚动并聚焦题目 |
| set_view | layout?, translation?, fontSize? | 上下/左右布局、关闭/逐句译文、14–22 字号 |
| navigate_page | page | 打开固定的软件页面 |

`occurrence` 从 0 开始，重复引文必须明确指定。一次最多 8 个操作，同批只针对一个篇章；打开其他页面必须单独执行。此版不代替用户作答、交卷、删除数据、修改 AI 配置或运行任意代码。非阅读页目前提供问答和页面导航，尚未接入词表筛选、复习评分或设置表单操作。

## 实现

- `electron/page-assistant.cjs`：声明式协议、引文原文偏移、操作/篇章/题目校验，以及页面上下文提示词。
- `assistant:run` IPC：从数据库加载真实材料与有效题目，调用现有 AI 网关；整批校验成功后原子保存问答，仅返回规范化的操作。
- `usePageAssistant.js`：全局对话与请求身份、取消、历史加载、页面上下文注册。历史只保存回答，不包含可重放的操作。
- `PageAssistant.vue`：独立全局面板，支持扩大阅读和键盘操作。
- `ReaderAssistant.vue`：阅读器操作执行、生命周期校验、高亮、浮动讲解与原文追问。
- `page-anchors.js`：在 Vue 管理的 DOM 文本节点中定位 Range；仅规范化空白，保留原文，不改写正文 DOM。CSS Custom Highlight API 绘制标注。

当前文章优先进入上下文；全部正文节选合计最多 40,000 字符，当前文章最多 18,000 字符，其余篇章最多各 4,000 字符。仅发送相关页面材料、选文、最近对话与检索资料，不把设置里的 Key 放进模型提示词。材料和检索内容作为参考数据处理。

兼容常规 chat/completions 接口，不要求服务支持原生工具调用。约定模型返回 `{reply, actions}` JSON；纯文本回答可正常展示但不会执行操作。「就地讲解」的纯文本回答也会由软件绑定到用户实际选中的原文。

## 验证

所有界面验证均使用独占临时数据库和本地模型响应，不调用付费模型，也不使用真实用户学习记录。

```powershell
node node_modules/vite/bin/vite.js build
node scripts/regression-page-assistant.cjs
node scripts/page-assistant-check.mjs
npm run test:regression
node scripts/verify-all.mjs
```

界面测试覆盖多处高亮、就地讲解、布局切换后重定位、跨篇章题目定位、草稿保留、伪造引文拒绝、取消连接、历史清理与不重放。可通过 `KEEPER_ASSISTANT_ARTIFACTS` 指定截图保存目录。

本轮结果：既有功能回归 258 项、新增协议与状态回归 12 项、新增真实界面检查 29 项、既有端到端 150 项、AI 取消与恢复真实界面 24 项通过；Vite 构建、345 个跟踪文件密钥扫描、311 篇正文/译文字符守恒与 78 篇段标检查通过。最后的固定工具栏点击与导航结果确认改动另经新增界面检查覆盖。

本地响应验证的是软件执行与交互链路；真实模型对自然语言意图、证据句与讲解质量的表现仍需使用者所配置模型的后续评估。
