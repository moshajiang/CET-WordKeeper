# 原文短语收藏与独立复习

2026-10-25，P3 第一批，开发基线 `6f5f456`。完成「划选原文 → 填写此处释义 → 收藏管理 → 审阅候选卡 → 独立复习 → 返回原文」流程。当前为源码功能，尚未制作新安装包。

## 使用方式

1. 在阅读器完整划选 2 至 12 个英文单词，点击划选菜单的“收藏短语”，或点击原文上方的“收藏划选短语”。窗口会核对实际原文，显示引文、上下文和出处。
2. 填写这个语境中的释义，可补充备注与标签，再点击“保存短语”。保存前可以取消；有未保存内容时离页或关闭需要确认。收藏不调用 AI，也不自动创建复习卡或消耗每日新卡额度。
3. 左侧“短语收藏”可按短语、释义、上下文、备注和出处搜索，也可按标签筛选。选中后编辑释义、备注或标签，或移入回收站。回收站可恢复完整收藏。
4. 点击“返回原文并定位”，回到原篇章，准确高亮收藏时的那处短语并展示本人填写的释义。相同文本多次出现时使用保存的出现序号；原文变化或移除后停止自动定位，保留收藏时的上下文供阅读。
5. 点击“制作短语练习卡”，先展示可编辑问答候选，包含原文上下文、短语目标、已保存释义与出处。核对后勾选保存，可另选“保存后加入复习”。已有练习卡页面也能在来源中选择短语、手动制作或明确点击 AI 生成候选。
6. 练习卡沿用每日额度、每轮计划、先回忆再翻面、评分及历史保存。新建且尚未作答的短语卡也具备新卡 FSRS 试用资格；是否启用仍需逐张预览并确认。

同一原文版本、同一出现位置重复收藏会返回原收藏，提示保留已有释义，不静默覆盖。不同位置或不同篇章可各自收藏，即使短语相同也保存各自的语境。这一批尚未提供跨出处自动合并或熟词词义归并。

收藏释义更新后，已制作的卡片保留原题面、答案、来源快照与历史，提示来源资料已变化。需要改变学习目标时由用户审阅编辑卡片，沿用改题重学规则。移入回收站不会删除卡片和作答；卡片仍能复习，来源提示暂不可用，恢复后重新可读。

## 数据与实现

- `electron/phrases.cjs`：独立收藏服务；`phrase_item` 保存 UUID、真实 exam/passage 身份、引文与出现序号、原文偏移和 SHA-256、上下文快照、出处标签、释义、备注、标签、版本及回收时间。
- `phrase_operation` 保存创建请求的操作身份、载荷摘要及回执。相同请求重试不重复创建，同一操作身份不能换内容。重复收藏也保存明确回执；回收站中的重复项提示先恢复。
- `phrase:prepare` 只读核对实际原文，拒绝跨卷 ID、缺失/退休材料、无效重复序号、单词碎片与超出长度的划选。保存需带预览返回的原文摘要；正文变化后旧预览不能提交。
- 保存、编辑、移入回收站和恢复使用主进程事务，落盘失败回滚内存与数据库；编辑和回收状态使用整数版本校验，拒绝过期覆盖。增量建表，原始备份必需 SCHEMA 不变，旧备份仍可恢复。
- `PhraseCapture.vue`：就地收藏窗口、明文表单、焦点约束与恢复、操作期间保护、保存后快捷进入管理。传入 IPC 的对象先转普通载荷，避免 Vue 代理造成结构化克隆失败。
- `PhrasesView.vue`：独立搜索筛选、编辑、回收恢复、来源定位与候选卡入口；离页保护和迟到请求身份检查。列表按篇章批量计算来源摘要，避免每条收藏分别查询正文。
- `ReaderAssistant.vue` / `ReaderView.vue`：沿用真实 DOM Range 与空白映射，不替换文章 DOM；已有批注、高亮、划选讲解和页面操作继续工作。本人短语释义与 AI 讲解的来源标识区分，转存笔记不会误标 AI 生成。
- 练习卡使用稳定来源 `phrase:<uuid>`，由统一来源适配器读取收藏，不复制成可独立编辑的知识库正文。卡片来源快照与摘要沿用原机制；来源变化不会自动修改旧卡。现有内置和个人资料的来源接口兼容。
- AI 候选仍仅在用户明确点击后调用其配置服务，相关收藏内容作为参考数据发送；生成结果先审阅，不自动入库。本批没有自动推断释义或后台模型请求。

## 后续顺序

P3 尚未整体完成。下一批先支持单词的多个语境义与真实出处，再加入短语/词义的拼写和原句填空练习，最后完善含出处的导出。不同含义各自对应学习目标，不自动合成超长卡；既有词形归一和生词统计继续复用。AI 建议释义放在手动流程之后，明确待确认，不覆盖已有解释。移动复习与同步仍留在 P4。


## 多个语境义（2026-10-26）

当前增加独立“语境义”入口，复用原文收藏能力但按类型分开显示；支持完整单词的逐处释义和现有词形归一。同词不同语境可关联查看、分别制卡，生词本有直接入口。上下文增加独立目标偏移，候选题用【】标明具体目标；旧记录仅在原文仍匹配时只读推导，不猜测陈旧位置。短语原 ID、回收和保存回执兼容。详见 [CONTEXTUAL-SENSES.md](CONTEXTUAL-SENSES.md)。


## 拼写与填空已接通（2026-10-26）

短语详情可选择拼写或原句填空后制作候选；重复短语线索会遮挡，核对参考表达后再评分。候选仍需审阅保存，收藏本身不入队、不计额度。详见 [TYPED-PRACTICE.md](TYPED-PRACTICE.md)。


## 带出处导出（2026-10-26）

管理页支持按当前筛选预览并导出 JSON 资料档案或 Anki 导入文本，保留原文与出处。练习卡 JSON 可选全部作答与调度记录，完整恢复仍使用数据库备份。格式、范围与使用步骤见 [LEARNING-EXPORT.md](LEARNING-EXPORT.md)。
