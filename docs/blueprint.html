1项目概述

一句话定位：一款把「刷真题」和「背单词」合并成一个动作的桌面学习软件。你在真题原文和解析里阅读时，点一下不认识的词，它就带着出处句子进入你的专属生词库，之后按遗忘曲线安排复习。

阅读真题→ 点词标注→ 生词入库（带真题语境）→ SM-2 间隔复习→ 语境中真正掌握

与传统背单词 App 的核心差异：每个生词都自带你在真题里遇见它的那句话。复习时看到的不只是孤立的词，而是真实考试语境，同时系统天然统计出「这个词在历年真题中出现了多少次」，高频考词一目了然。

功能具体需求

3技术选型

层选型理由
应用壳Electron 33+本机已有 Node 22 无 Rust 工具链，Electron 零原生编译、生态最成熟；安装包约 90MB，桌面场景可接受
前端Vue 3 + Vite + TypeScript阅读器是重交互场景，Vue 响应式适合词级高亮状态管理；Vite 热更新快
本地数据库sql.js（WASM 版 SQLite）纯 WASM 无需 node-gyp 编译（规避 better-sqlite3 在 Windows 上的 MSVC 依赖坑）；数据落盘为单文件 keeper.db
词典数据ECDICT 裁剪版77 万词条开源词典（含音标/释义/考纲标签/词频/词形交换），裁剪保留 CET 考纲 + 高频词约 4 万条，体积约 15MB
AI 服务OpenAI 兼容协议网关默认适配 DeepSeek（便宜），兼容 Kimi / GLM / OpenAI；仅句子翻译、语法分析、错因分析走 API，全部结果本地缓存
语音朗读Chromium SpeechSynthesisElectron 内置，离线免费，支持英/美音切换与语速调节
真题处理Python + pdfplumber（构建期工具）数据工程阶段离线处理，不进入运行时
查词 100% 离线可用（本地词典 + 本地 TTS）。只有用到「整句翻译 / 语法分析 / AI 错因」时才需要联网和 API Key，且全部结果缓存，同一句话只请求一次。

关键设计点：

  • 词级渲染：文章在渲染层按 token 切分为 <span class="w" data-word>，高亮只是 class 切换，万词长文流畅
  • 词形归一：查询前经 ECDICT exchange 字段还原原形（went→go, studies→study），标注按原形聚合
  • AI 网关统一出口：请求签名哈希入 ai_cache 表；无 Key 或断网时自动降级（句子翻译隐藏、语法分析提示），不阻塞其他功能
  • 数据安全：单文件 SQLite + 一键备份/恢复（复制文件），换电脑迁移零成本

5功能模块设计

5.1 真题阅读器（核心）

  • 结构：左侧文章流（听力原文 / 阅读篇章 / 翻译原文 / 写作题目），右侧对应题目与答案解析，联动滚动定位
  • 单击单词 → 查询浮层（见 5.2）；浮层内「★ 加入生词本」即高亮
  • 双击单词 → 直接入库（无浮层，最快路径，可撤销 toast）
  • 划选文本 → 浮动菜单：「整句翻译」「语法结构分析」「加入生词本（多词）」
  • 做题模式：题目可直接作答，即时判分；答错自动进错题本
  • 颜色约定：生词 = 黄色底纹；已掌握 = 绿色底纹；超纲词（难词预扫开启时）= 紫色虚线下划线

5.2 查询浮层（本地词典）

单击词后 10ms 内展示（纯本地查询）：

  • 单词 + 音标（英/美）+ 🔊 发音按钮（TTS）
  • 考试分级标签：CET4 / CET6 / 考研 / 雅思托福 / GRE（来自 ECDICT tag 字段）
  • 中文释义 + 英文简单释义；词频星级（BNC/COCA 词频）
  • 该词在全部真题中的出现次数及例句（点击跳转到出处）
  • 操作区：★ 加入/移出生词本 · ✎ 添加私人笔记

5.3 生词本与复习系统

SM-2 间隔重复算法（Anki 的经典内核）：

新词 → 1天后复习 → 6天后 → interval × ease_factor 逐次拉长
评分：忘记(重置,10分钟后再现) / 模糊(间隔×1.2) / 记得(间隔×EF)
连续 3 次「记得」且间隔 ≥ 21 天 → 提示可标记「已掌握」
  • 每日队列 = 到期复习词 + 每日新词配额（默认 20，可调）
  • 四种复习模式（可单选或混合）：
    1. 认词：看词 → 心中回忆 → 翻面看释义与真题语境句
    2. 听音辨词：TTS 播放 → 选出正确拼写
    3. 听音拼写：TTS 播放 → 键盘拼写出词
    4. 语境填空：你的真题出处句挖空该词 → 填入（最高效模式）
  • 生词列表：按来源考次 / 状态（学习中·已掌握）/ 真题出现次数 / 添加时间筛选排序，支持批量导出

5.4 难词预扫

  • 打开任意篇章时后台分词，逐词查 ECDICT 考纲标签
  • 识别两类：① 超纲词（超出当前级别考纲的词，如四级卷中的 GRE 词）② 高频考词（真题出现 ≥ 3 次的考纲词）
  • 侧栏展示清单 + 正文紫色虚线微标注；支持「一键将本篇超纲词全部加入生词本」
  • 用于读前心理预期管理：先扫一眼难词，再读文章，阅读流畅度显著提升

5.5 错题本

  • 阅读器内作答即判分，错题自动入库（含题目、你的答案、正确答案、原文出处句、官方解析）
  • AI 错因分析（可选，走 API）：分析错误选项为何错、原文证据在哪、属于词汇问题还是逻辑问题
  • 按题型（选词填空 / 仔细阅读 / 长篇阅读）分组，支持「重做错题」二次作答

5.6 Anki 导出

  • 生词本（可按筛选条件）一键导出为 Anki 可导入的 TSV：正面 = 单词 + 音标 + 出处句（挖空），背面 = 释义 + 解析
  • 兼容 Anki 直导（文件 → 导入 → 选择字段分隔符），二期可升级直接生成 .apkg 牌组（含发音媒体）

5.7 真题导入与扩展（用户自定义数据）

软件内置真题之外，用户可随时导入自己的真题/学习材料，与内置数据完全同权：

  • 导入格式：结构化 JSON（软件提供模板与字段说明）；纯文本可快速导入（自动按段落切分篇章，不带题目）
  • 导入来源：任意考次（含更早年份、模拟题）、其他考试材料（考研英语阅读等）均可
  • 自动处理：导入即触发分词统计 → 更新全局词频表（高频考词识别随之更新）→ 纳入难词预扫与标注体系
  • 管理：真题库中「我的导入」分组展示，支持删除/重新导入；生词出处照常记录与跳转

6数据模型

单文件 SQLite（keeper.db），用户数据与内置数据同库分表，备份 = 复制一个文件：

-- 真题库（软件预置，只读）
exam(id, level, year, month)                    -- 考次：CET4/CET6 × 年月
passage(id, exam_id, section, seq, content)     -- 篇章：听力/阅读/翻译/写作
question(id, passage_id, qtype, stem,
         options_json, answer, analysis)         -- 题目+选项+答案+官方解析

-- 词典（ECDICT 裁剪，只读）
dict(word PRIMARY KEY, phonetic_us, phonetic_uk,
     translation, definition, tag,              -- 考纲分级标签
     frq, exchange, collins)                    -- 词频 / 词形交换 / 星级

-- 用户数据（读写）
user_word(id, word UNIQUE, status, note,        -- status: learning|mastered
          created_at, mastered_at)
word_hit(id, word, passage_id, sentence)        -- 真题出现记录（自动统计）
review_log(id, word_id, mode, rating,
           reviewed_at, interval, ease, due)     -- SM-2 调度数据
mistake(id, question_id, user_answer,
        ai_analysis, created_at, redone)         -- 错题本
ai_cache(hash PRIMARY KEY, kind, response)      -- 翻译/语法分析缓存
settings(key PRIMARY KEY, value)                -- API Key / 每日新词量等

7数据工程管线（构建期）

CET46-Resources 真题 PDF→ pdfplumber 文本抽取→ 清洗（去页眉脚/还原双栏）→ AI 辅助按题型分块→ 人工抽检校对→ 结构化 JSON→ 导入 SQLite
  • 首发范围：2020–2026 年四六级共 14 个考次（每考次多套卷），约 90+ 篇文章；后续版本可滚动补全至 2014 年起全量 55 考次
  • 分词统计产出真题词频表（供高频考词识别与「出现次数」展示），随数据包内置
  • ECDICT 裁剪：保留 tag 含 cet4/cet6/ky（考研）及 BNC 词频前 2 万的词条，约 4 万条、15MB
版权说明：真题数据仅供个人学习使用，软件不分发真题原文；若未来公开分发安装包，真题数据包需用户自行导入（软件提供导入功能作为合规通道）。

10风险与应对

风险应对
真题 PDF 解析质量参差（双栏/表格/页眉噪声）AI 辅助分块 + 人工抽检双保险；首发只做近 6 年控制校对成本；解析失败的考次宁缺毋滥
无 API Key / 断网时功能不可用核心链路（查词/标注/复习）100% 离线；AI 功能自动降级并明确提示，不阻塞

真题版权个人学习使用；安装包不含真题数据时提供「自行导入」合规通道
