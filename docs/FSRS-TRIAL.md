# 新练习卡的可选 FSRS 试用

> 2026-10-30 发行补充：本页已实现的桌面功能随 v0.3.4 分发，见 [发行记录](RELEASE-0.3.4.md) 与 [使用指南](../README.md)。下文“源码交付/未打包”等描述保留为对应日期的历史记录；移动演示和后续计划不属于桌面正式功能。

2026-10-25，P2 第三批，开发基线 `5ab8dd0`。本批允许最多 10 张从未作答的新练习卡单独使用 FSRS，提供四档评分、自动备份及保留全部作答的退出方式。旧词汇和其他卡片继续使用原调度，设置页的历史对照仍完全只读。

## 使用流程

1. 在“练习卡”管理页选中一张从未作答的新卡，在“调度方式”选择目标保持率 80%、90% 或 95%，点击“预览 FSRS 试用方案”。默认 90%，预览不写数据库。
2. 核对本次只影响一张卡、切换前后到期时间与试用数量，再点击“备份并启用 FSRS”。切换前生成并校验本机完整数据库备份；未完成备份不能切换。
3. 复习仍先独立回忆，再看答案与预计间隔。只有这张卡显示四档：**没想起、费力想起、正常想起、很轻松**。“费力想起”要求已经回忆成功。客观题选错只能选“没想起”，主观题由用户核对后自评。
4. 若想退出，在同一管理页点击“预览退出试用方案”，核对接续的原调度时间，再点“备份并回到原调度”。退出也先备份；保留试用作答、题目快照与 FSRS 状态，后续按原三档继续学习。
5. 最近一次切换的备份位置可在详情展开查看。备份位于用户数据目录的 `scheduler-backups/`，包含学习数据与 AI 配置，应按个人数据妥善保存。本功能不自动清理这些备份。

暂停或未入队的新卡可以启用试用，但不会自动入队或恢复复习；归档卡需要先恢复。暂停和归档中的试用卡仍占 10 张名额，退出释放名额。本批每张卡只参加一次，退出后不重复开启。已有作答、首次学习身份或复习进度的卡不能加入，避免把含义不明的旧三档评分强行迁移。

目标保持率是调度输入，不是学习效果保证；不同档位的实际时间以当前卡状态计算并显示。本批未训练个人参数，不因单次间隔变化宣称效果提高。每日新卡额度、每轮上限和目标时长继续生效，退出或改题不重置当天已消耗额度。

## 回退如何保留学习进度

试用期间，每次真实评分除计算 FSRS 外，还同步计算一份原卡片调度状态。该状态使用实际评分时间和以下明确映射：

| FSRS 原始档位 | 原调度的兼容评分 |
| --- | --- |
| 1 没想起 / Again | 0 不会 |
| 2 费力想起 / Hard | 1 模糊 |
| 3 正常想起 / Good | 2 会用 |
| 4 很轻松 / Easy | 2 会用 |

原始四档及语义版本 `fsrs-4-v1` 单独保存，详情显示原档位；兼容映射只用于原表及回退状态，不把旧“模糊”反推为成功回忆。退出使用试用期间这些实际作答所积累的原调度状态接续，**不恢复旧备份覆盖新记录**。未入队卡保持未入队，已经入队但尚未评分的卡保持入队，暂停和归档状态保持原样。

改题型、题目、选项或答案会为新内容重建 FSRS 记忆与原调度状态，增加内容轮次 `epoch`；参数、旧题作答快照和重置事件保留。只改标签或解析不重学。移出队列再加入保留 FSRS 已计算的到期安排，避免将尚未到期的卡变成立即到期。

## 实现与数据约定

- `electron/practice-fsrs.cjs` 负责逐卡资格、方案、四档调度、同步原调度、内容重学及退出。每卡保存库版本、完整参数及 SHA-256 版本、记忆状态、原调度状态、内容摘要和轮次。
- 沿用精确锁版的 `ts-fsrs@5.4.2` / FSRS 6。使用官方默认权重，最长间隔 365 天、关闭随机扰动、开启短期学习、学习/重学步骤各 10 分钟。参数在启用时固定，本批不能中途修改；不增加训练组件或上传日志。
- 增量表 `practice_fsrs`、`practice_fsrs_operation`、`practice_fsrs_review`、`practice_fsrs_event` 分别保存逐卡状态、切换幂等回执、原始四档/官方日志及前后状态、启用/退出/改题事件。基础备份必需 SCHEMA 不变，旧备份仍可导入。
- 新 IPC `practice:trialPreview` 只读，`practice:trialCommit` 必须携带方案摘要、卡片版本及 UUID。状态或试用数量变化后需重新预览；相同成功请求重放返回原回执。前端在操作期间阻止切换卡片或离页。
- `electron/scheduler-backup.cjs` 在修改数据库前导出完整内容，写入专属临时文件、逐字节校验、重命名、再次校验。备份名包含操作身份及内容摘要；重试会核对已有备份，不能覆盖不匹配文件。只清理本次失败的临时文件。
- 实际评分、原始四档日志、FSRS/原调度状态、卡片到期、作答及每日首次学习身份在同一事务落盘；失败整体回滚，按同一身份重试不重复。切换写盘失败时保留有效备份，不留下半张试用卡。
- 评分请求明确携带 `ratingScale`；旧三档不能误评试用卡，过期四档也不能误评退出后的卡。时钟倒退、内容或参数版本不一致、状态损坏时拒绝评分，仍允许依照完整的原调度状态退出。
- 设置页旧历史对照跳过参加过试用的卡（包括已退出者），给出明确原因，避免把四档映射记录混入旧三档回放。

官方来源：[固定版本卡片字段与四档类型](https://github.com/open-spaced-repetition/ts-fsrs/blob/v5.4.2/packages/fsrs/src/models.ts)、[固定版本用法](https://github.com/open-spaced-repetition/ts-fsrs/blob/v5.4.2/packages/fsrs/README_CN.md)、[官方评分语义](https://github.com/open-spaced-repetition/fsrs4anki/blob/main/docs/tutorial.md)。库与许可证核对记录见 [SCHEDULER-EVALUATION.md](SCHEDULER-EVALUATION.md)。
