# 熟词生义与多个语境义

2026-10-26，P3 第二批，开发基线 `7a3a41b`。增加单词在真实原文中的逐处释义：同一个词可以有多个语境目标，各自保留出处、解释与练习卡。当前为源码更新，尚未制作新安装包。

## 使用方式

1. 在阅读器点击一个英文单词，在查词框选择“保存此处词义”；也可完整划选一个英文单词，在划选菜单点同名按钮，或点原文上方“保存划选词义”。短单词同样支持划选。
2. 窗口显示原文词形、归一词形及上下文。填写**这个语境中的意思**，可加备注与标签，再保存。手动流程不调用 AI，不覆盖词典释义或生词本进度，也不自动加入复习。
3. 左侧“语境义”查看所有收藏；可按词形、释义、上下文、出处和标签搜索筛选。详情显示同词的其他语境，支持逐条切换；“只看某词的语境”筛出同一归一词形。详情最多列最近 20 处其他语境，完整记录可在列表中筛选查看。
4. 生词本的“查看语境义”打开全部记录，单词详情的“查看这个词的语境义”直接按当前词筛选。没有收藏时引导返回原文；不从词典批量虚构遇见记录。
5. 点击“返回原文并定位”，高亮保存时的准确出现位置，显示本人填写的解释。原文更新或移除后停止自动定位，保留收藏时的上下文。
6. 点击“制作语境义练习卡”，先审阅可编辑候选。题面保留上下文，并用 **【】** 标出该次目标，避免同一句中重复单词导致含义不清。保存时再决定是否加入复习；同词不同语境分别建卡，答案和作答历史各自保留。

例如原文中的 “The sun sets …” 和 “She sets a limit …”，可分别填写“落下”和“设定”。两处都关联归一词形 set，但各自保存原文 sets、出现序号、目标位置与解释，不自动把它们合成一张大卡，也不自动认定它们属于哪个词典义项。

修改、回收、恢复沿用版本校验和保存保护。修订一处释义不修改其他语境，不覆盖已制作卡片的答案或旧作答快照；回收收藏不删除卡片。候选卡之后仍可明确点击原有 AI 生成入口，生成结果需要审阅，默认不请求模型推断释义。

## 词形与数据边界

- 复用现有 `resolveWord`，采用字典确认的归一结果；无法确认的词保留完整原文形式并统一大小写/撇号，不拿猜测出的截词结果强行归并。归一词形在保存时确定，不因阅读或筛选重写已有记录。
- 语境义保存的是一次真实遇见及用户解释，不是新增一条生词。词典、user_word 掌握状态/笔记/到期、词频、word_hit、旧评分和每日新词额度保持原样。只有明确保存并评分练习卡后，才产生对应卡片的学习记录和新卡额度。
- `phrase_item` 增量添加 `kind`、`lemma`、`context_offset`。旧条目默认 kind=phrase、lemma 为空，原 ID、出处、版本及回收记录保留。原短语保存操作的载荷摘要格式保持兼容，旧回执可重放。基础备份必需 SCHEMA 不变。
- 短语和语境义共享原文校验、事务、幂等、管理组件及回收机制，但按 kind 分开列出。来源使用 `sense:<uuid>`，原短语来源继续使用 `phrase:<uuid>`，主进程校验类型和完整身份。
- `context` 保存未经标记的原文窗口，`context_offset` 单独保存该处目标位置；`markedContext` 由主进程根据原始引文生成。客户端传入的词形、上下文、出处和目标偏移不会覆盖服务端核对结果。
- 旧记录未保存上下文偏移时，只有原文摘要及保存窗口仍一致才在读取时推导，不写回数据库。陈旧且无法确认的旧记录不猜测定位。原短语来源的正文格式保持兼容，避免仅因升级而把所有旧卡标为来源变化。
- 新语境卡沿用每日额度、每轮计划、评分幂等及新卡 FSRS 资格；实际是否启用 FSRS 仍需按卡预览和备份确认。旧词汇调度公式及已有卡片不改变。

## 本批顺带修复

1. 原划选身份最多查 100 次匹配，常见词超过该次数会默认指向首处。改为一次遍历正文映射，再按真实 DOM Range 确认出现序号，不再使用该截断。第 121 处实际划选已通过真实界面验证。
2. 同一短语/单词在短上下文中多次出现时，候选题之前无法明确哪一处。新增独立目标偏移，在候选上下文用【】标出，不修改原始文本快照。
3. 收藏已有 12 个用户标签时，再追加系统标签会超过卡片上限。来源标签现在保留全部用户标签，达到上限时不额外追加系统标签。
