# 语境挖空与词频语义：第四批 4G

日期：2026-10-19。源码版本保持 0.3.1；全部运行测试使用独占临时数据库。

## 已确认的问题和处理

原 ReviewView 使用子串正则，`art` 会误遮住 `partial`，`go` 又无法命中原句 `went`。Anki 的高亮有同类问题。现在由 word-semantics 模块按完整单词、词典原形和原句位置标记，重复出现的同原形词全部处理；`runners` 不会随 `run` 一起遮住。保留实际原句的大小写、曲撇号和屈折形式。数字/下划线等标识符中不截取半个单词，连字符复合词不拆成目标词。转义原始正文后才插入程序固定的标记，避免把例句里的 HTML 当作界面或 Anki 标签执行。

复习优先选择最新且能准确定位目标词的收藏原句；较新的错误出处不会挡住较早的有效句子。所有旧出处都找不到目标时使用普通词卡，翻面仍可查看原句。没有新增异步前端请求；IPC 返回经过转义的 clozeHtml。Anki 的所有纯文本字段同时转义、移除制表符、转换换行，保持五列格式。

## 词频定义

- 范围为有效 exam 下未 retired 的 passage.content，含内置与用户导入，各 section 沿用原范围。不读题干、选项、译文、参考答案或用户笔记。
- total 是包含该原形的**篇数**，对应现有界面“篇 / 套”；同一篇的重复词和多个屈折形式只记一次。exams 是涉及考次去重数。
- 词形判断与运行时查词共用同一解析器，保留词典显式原形、反向变形、精确词条和兜底的优先级，不新增歧义词猜测。
- 延续实词统计的停用词集和三字符门槛，在原始形式及归并后的原形上均检查，避免 having 把 have 混入、goes 把两字符 go 混入。未知词不统计。连字符/撇号属于词内字符，句末引号作为标点；曲撇号统一用于查词但原文不改写。

## 迁移与回退

使用 content_sync_state 中独立的 word-frequency / lemma-passages:v2 标记；即使内置正文没变，旧库也执行一次重算。迁移前沿用 SHA-256 命名的原文件完整备份和字节校验。重算先完成内存计数，再在可嵌套 SAVEPOINT 中替换频率表与版本标记；SQL 失败回滚，外层导入事务也可以一起回滚。启动写盘失败恢复迁移前内存，磁盘原文件保留；备份失败禁止迁移保存。成功后二次启动不重算、不新增备份、不改数据库字节。

分发 data/keeper.db 本批不直接覆盖；新程序复制种子后也会按版本迁移。后续重新构建种子采用相同计数函数并写入版本标记。学习表、内容 ID、草稿、成绩和 API 配置不因频率重算改变。
