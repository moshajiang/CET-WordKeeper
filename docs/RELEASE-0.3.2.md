# CET WordKeeper v0.3.2

2026-10-20 发布准备。对应分支：release/v0.3.2，基于双仓库同步的 236590e。

## 本次更新

- 设置页支持 GitHub / 码云更新来源，记住本机选择；校验发行标签、安装包与摘要，防止重复下载和切源冲突。
- 修复作答与作文草稿保存、切换篇章和关闭恢复问题；学习数据迁移、备份恢复补充失败回退。
- 完善 AI 请求取消、结果校验及聊天清空，避免迟到结果污染当前页面或数据。
- 修复阅读/背诵导航、查词收藏出处和词形统计；复核并修正五篇内置材料的对齐边界。

## 下载

- CET-WordKeeper-0.3.2-setup.exe：Windows x64 安装版，支持应用内下载更新。
- CET-WordKeeper-0.3.2-portable.exe：Windows x64 便携版，检测更新后手动下载替换。
- latest.yml 与 setup.exe.blockmap 为自动更新配套文件，需与同次构建的安装包一起发布。
