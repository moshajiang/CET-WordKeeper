# 独立练习卡

2026-10-25，开发方案 P1 已完成。当前为源码功能，尚未制作新安装包。已发布的 v0.3.3 标签和附件不变。完整阶段安排见 [LEARNING-ROADMAP.md](LEARNING-ROADMAP.md)。

## 使用方式

1. 在知识库打开资料，点击“制作练习卡”，或打开侧栏“练习卡”并选择来源。
2. 三种制作方式均先进入候选区：手动填写；把条目里的内置自测整理为候选；调用配置的 AI 一次生成 1、3 或 5 张候选卡。无 AI 配置时前两种方式和已有卡片复习仍可用。
3. 支持问答、翻译、判断、选择。逐张核对题面、答案、解析和标签，取消不需要的卡片，再“保存勾选卡片”。默认只保存；勾选“保存后加入复习”才进入到期队列。重复题会提示跳过，不重复新建；重复的归档题不会自动恢复或入队。
4. 卡片可按题型、标签、来源和状态筛选，搜索涵盖题目、答案、解析及来源标题。可编辑、加入复习、暂停、继续、移出队列、归档和恢复。归档恢复后默认暂停。
5. 首页提供独立练习卡到期入口，复习页新增“练习卡复习”。先作答后展开答案和解析。选择/判断题提供与卡片答案的对照；选错时不能评“会用”。问答/翻译保留自己的作答，由用户核对后自评，不伪造自动评分。
6. 管理详情可查看最近 50 次作答及当时题目、答案和版本。修改题型、题目、选项或答案会重置学习进度；已加入队列的卡片重新到期，旧记录保留。只修改解析或标签不改变调度。
7. 卡片保留制作时的来源正文。来源修改或删除后显示提示，已有卡片和作答历史继续可用；删除后打开资料会提示使用快照。来源恢复后可重新打开资料。

## 数据与请求约定

- `electron/practice-cards.cjs` 负责增量建表和数据服务，独立于词汇与知识点队列。旧 `knowledge_review` 不自动迁移、不复制。基础 `SCHEMA` 不变，旧备份可以继续检查和恢复；恢复旧备份仍以该备份内的数据为准。
- `practice_card`：UUID、题型和内容、来源 key/标题/正文/SHA-256、来源类型、标签、状态、到期时间、复习次数、间隔和递增版本。
- `practice_card_batch`：创建批次身份、规范化请求摘要和结果；用于处理重复点击及回执丢失。
- `practice_attempt`：评分操作身份、卡片版本及完整快照、用户作答、自评分、客观对照、作答时间、下次时间及请求摘要。编辑卡片不修改已保存记录。
- 保存与评分均通过 `persistTransaction` 统一写盘。批量保存先验证整批，写盘失败恢复内存，不留下半批卡片或多余日志。相同身份同内容重试不重复写入，不同内容复用身份明确报错。
- 编辑、改状态和评分携带 `expectedRevision`；过期请求拒绝覆盖。评分失败保留原操作，可重试；若当前卡已被修改，可重新加载队列。
- 三种制作方式均携带审阅时的来源摘要；资料在审阅与保存之间发生变化时拒绝保存旧候选，用户重新核对后制作。AI 生成后再次验证来源；停止/切来源/离页会使迟到结果失效。
- 题型、长度、标签、选项数量和客观答案在主进程验证。AI 返回的候选不会自动入库。卡片内容和来源使用安全 Markdown 渲染。
- 首页到期数使用索引计数查询，不读取所有卡片正文；列表不传输来源正文，详情和复习才读取快照。

P1 复用简单间隔：不会 10 分钟，模糊 1 天，会用按连续成功次数从 2 天逐步延长，最多 30 天。这是初版安排，尚未使用 FSRS。每批最多 30 张，到期多于一批时可继续加载。

## AI 边界

只有用户主动点击生成候选卡时才向所配置模型发送当前资料的标题与正文，正文上限 16000 字符；不发送 API Key 给模型作为提示内容。手动制作、内置自测整理和复习不请求模型。主观题不自动请求批改。模型答案仍需用户核对；专项测试使用本地响应，验证软件流程，不代表真实模型的教学质量。

## 实现位置

- `src/views/PracticeCardsView.vue`：候选审阅、保存、检索、管理和历史。
- `src/components/PracticeCardEditor.vue`：共用的四类题编辑器。
- `src/components/PracticeCardReview.vue`：先作答后核对、评分重试、独立到期批次。
- `electron/main.cjs`、`electron/preload.cjs`：IPC 与 AI 候选校验；`electron/study.cjs`：首页到期统计。
- `scripts/regression-practice-cards.cjs`、`scripts/practice-cards-check.mjs`：18 项数据、31 项界面检查；`test:cards` 已加入 npm 脚本，相关入口接入 CI。


## P2 复习节奏更新（2026-10-25）

原固定 30 张的练习卡批次现改为按设置的每日新卡额度、每轮数量和目标时长组成本轮。已学到期内容优先，可暂缓新卡或提前结束；首次作答计额度，编辑后重学不再次计为新卡。原有来源快照、版本校验和作答历史保留。详见 [REVIEW-PACING.md](REVIEW-PACING.md)。


## P3 短语来源（2026-10-25）

练习卡来源新增 phrase:<uuid>。在“短语收藏”选择“制作短语练习卡”，先核对含真实上下文的问答候选，再保存或加入复习；也可从来源下拉选择短语后手动新建或主动生成 AI 候选。来源按钮返回对应收藏。收藏释义修改、回收或原文更新不会重写既有题目、答案和作答快照；来源变化/不可用会提示。短语卡沿用原有每日额度、候选审阅、评分幂等及新卡 FSRS 资格。完整流程见 [PHRASES.md](PHRASES.md)。
