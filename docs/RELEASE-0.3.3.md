# CET WordKeeper v0.3.3

2026-10-22。本地安装包已构建；源码基于 3c783a9，打包分支 release/v0.3.3。尚未上传 GitHub / 码云 Releases。

## 本次更新

- AI 页面助手支持全局打开与展开；可定位真实文章、题目和篇章，划选内容后在原文附近显示讲解。
- 修复文字与空格之间的高亮白条，普通阅读与逐句对照均连续显示。
- 知识库支持全文阅读、搜索、分类标签和个人笔记编辑；内置资料可复制为笔记。
- 原文讲解可先整理为可编辑草稿，保存后能返回对应篇章并恢复引文高亮，包括重复句子的正确位置。
- 知识库旧资料增量迁移，保存和删除失败回滚。来源无法对应时保留笔记并明确报错。
