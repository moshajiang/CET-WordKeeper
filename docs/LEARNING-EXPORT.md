# 带出处的学习资料导出

2026-10-26。源码功能，尚未包含在已发布的 v0.3.3 安装包中。

## 使用方式

1. 打开“短语收藏”“语境义”或“练习卡”，先使用页面上的搜索、标签、题型、来源与状态筛选。
2. 保存或放弃正在编辑的内容和候选卡，再选择导出格式，点击“预览导出当前筛选”。
3. 核对条目数、样例和记录数，点击“选择位置并保存”。取消文件选择后预览仍保留，可以重新保存。

导出采用当前筛选结果，不限于选中的一条。收藏默认只包含“我的收藏”，切换到回收站可以导出回收记录；练习卡默认只包含“使用中”，需要暂停或归档卡时先改状态筛选。短语、语境义和练习卡分别导出，避免无意带入其他内容。

预览会固定当时已保存的数据，后续编辑不会悄悄改变本次文件。改变筛选或格式、取消导出、离开页面后需要重新预览；预览十分钟后失效。保存前不创建文件，成功保存后显示实际路径与数量。导出不调用 AI，不改变收藏、学习进度、调度、每日额度或数据库。

## JSON 资料档案

收藏包含原文表达、归一词形、此处释义、备注、标签、上下文、目标标记、出处及回收状态。每处出现位置保留自己的 UUID，多个相同表达不会合并。

练习卡包含六类题的题面、选项、答案、解析、状态、版本，以及制作时的来源正文和出处快照。默认只导出内容。勾选“附带全部作答记录及调度状态”后，会额外保存筛选卡片的全部历史，而非详情页最近 50 条：

- 每次作答当时的题目、答案、来源快照、原输入、评分、客观结果与到期时间。
- 拼写/填空的核对规则版本及规范化结果。
- FSRS 原始四档及对应旧评分、库/参数版本、前后记忆状态和官方日志。
- 当前实际调度、逐卡 FSRS 参数、同步计算的原调度状态及试用轮次。

档案顶层标识为 `cet-wordkeeper-learning-export`、`version: 1`，包含导出时间、筛选条件、条数、作答数与 `entries`。它是内容和可选学习记录档案，当前没有 JSON 导入/恢复功能；完整恢复仍使用设置页的数据库备份。档案不含 AI 设置、密钥、本机备份路径、操作回执或未选择卡片的数据。用户自行写入题目、备注等字段的内容会原样成为资料的一部分。

新卡增量保存 `practice_card.source_anchor`，由主进程从真实来源生成，不能由客户端指定；后续来源变化不会覆盖它。旧卡和旧历史缺少锚点时，仅在现有来源标题与正文摘要仍匹配时只读补充出处，标记 `anchorBasis: matching-source`；不匹配则保留原正文快照，锚点为空并标记不可得，不猜测位置。已有锚点标记为 `saved-with-card`，无定位信息的来源可为 `none`。收藏的原文变化或退休也不会改写已保存语境。

## Anki 导入文本

导出为 UTF-8 的制表符分隔文本，四列依次为 **ID / Front / Back / Tags**。文件头声明 tab 分隔、HTML、字段名及第四列为标签；推荐使用支持这些声明的 Anki 2.1.54 或更新版本。首次导入需要建立自己的三字段笔记类型：

1. 字段为 `ID`、`Front`、`Back`，ID 放在第一位。
2. 正面模板为 `{{Front}}`，背面模板为 `{{FrontSide}}<hr>{{Back}}`。
3. 导入文件，按字段名映射前三列，第四列映射标签，启用 HTML。检查导入预览和重复处理设置。

ID 使用 `CETWordKeeper:phrase:<uuid>`、`CETWordKeeper:sense:<uuid>` 或 `CETWordKeeper:card:<uuid>`，在同一笔记类型内用于识别重复。保留 ID 后再导出同一条编辑记录，可以按 Anki 的重复处理选项更新已有笔记；不同出现位置拥有不同 ID。这里使用自定义首字段，不占用 Anki 内部 GUID，遵循 [Anki 官方文本导入说明](https://docs.ankiweb.net/manual/importing/text-files)。

收藏正面显示表达与标记过的上下文，背面显示此处释义、备注、原文及出处。练习卡正面显示题目/选项，背面包含参考答案、解析、制作时的原文快照和出处。六种题型均导出为普通正反面卡，拼写/填空按参考答案自行核对；不会自动创建输入核对或 Cloze 笔记模型。原学习进度、评分历史、FSRS 参数与每日额度不传给 Anki，其复习安排由 Anki 决定。

用户文本经过 HTML 转义，换行转换为 `<br>`，制表符转义；引号按照分隔文本规则处理。标签中的空白转换为下划线。导出已通过独立分隔文本解析与真实 Electron 文件检查，尚未在 Anki 应用内做实际导入验证。

## 文件保存与限制

- 每次最多 5000 条、附带历史最多 50000 次作答，原始文本预检上限 4 Mi 字符，最终文件不超过 32 MiB。超限明确要求缩小筛选或关闭历史，不静默截断。
- JSON 使用 `.json`，Anki 使用 `.txt` 或 `.tsv`。通过原生对话框确认已有文件后可替换；程序直接指定路径时拒绝覆盖。
- 拒绝覆盖应用目录、用户数据目录中的非 `exports` 文件、符号链接和硬链接。先写独占临时文件，校验、刷盘后原子改名；失败清理临时文件并保留原文件。
- 预览绑定发起窗口及随机令牌；新预览或离页取消会使迟到的保存失效。重复保存请求返回原回执，不再次弹框或写文件；外部改动已保存文件后要求重新预览。

## 开发验证

运行 `npm run test:learning-export`：20 项数据/状态检查与 22 项真实 Electron 界面及文件检查。覆盖筛选、回收/归档、来源修改与退休、旧卡兼容、完整历史、FSRS/拼写记录、稳定 ID、转义、预览只读与冻结、取消/迟到请求、原子写入故障、路径保护、超限与重启。保存对话框只在隔离测试进程中替换，无产品测试开关。相关练习卡、FSRS、拼写、短语与语境义专项另外回归，全部使用隔离数据库，不触碰真实用户数据。


## AI 辅助来源（2026-10-26）

确认保存的 AI 释义在 JSON 收藏档案中附带 meaningProvenance，包含模型、生成/确认时间、原候选、解释、原文依据及人工修改标记；未确认候选不导出。Anki 收藏背面与新制卡来源正文保留 AI 辅助标记。流程见 [AI-CONTEXT-MEANING.md](AI-CONTEXT-MEANING.md)。
