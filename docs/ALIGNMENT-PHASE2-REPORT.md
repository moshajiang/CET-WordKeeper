# 第二批：正文显示与对齐修复记录

日期：2026-10-19。开发基线：第一批数据安全修复后的 release/v0.3.1 工作区。

## 代码修改

- F04：token 缓存归属于当前 computed 对照行；切换篇章清除译文展开状态，避免旧英文与新译文混配。
- F06：只删除带明确括号/点号的段落标记，保留 Joy / How / Are / I 等正常开头；全角标记与无空格形式均有回归。
- F07：DP 词典评分改为读取句子对象的 text；加入一个开启词典就会改变配对的确定性回归样例。
- 异步词典改为响应式浅引用；并发加载去重、失败可重试，Reader/Recite 两个实际 computed 都验证过重算。
- 补词按本篇题号与答案解析，不固定 26–35；支持 36–45、下划线与紧贴正文的编号，歧义编号不替换。
- 重写段落标记配对：点号仅识别行首，避免 U.N. / J. Smith 被误拆；括号标记兼容行内译文；连续同字母标题和正文合并，只使用一次译文。
- 构建与候选重建共用词典转换；增加只输出候选库、不就地覆盖输入的 rebuild-alignment 脚本。
