# 学习体验与功能联动

2026-10-23。本轮功能已加入源码；当前已发布的 v0.3.3 安装包与标签保持原样，尚未制作包含这些改动的新安装包。

## 使用方式

1. **首页续学**：继续上次篇章，查看未交卷题数，单独打开作文或翻译草稿。最近学习按真实访问时间排序，无到期生词时优先引导阅读；保留原有学习概况。旧版本只在本地记录的最后一次阅读会在首次打开首页时导入有效的访问记录。
2. **阅读模式**：练题关闭译文与答案，精读使用逐句对照，复盘展示解析并提供错因整理。模式、布局、字号和篇章位置按试卷记忆；切模式不删除作答。高级阅读设置折叠展示。写作和翻译不展示空客观题栏。
3. **AI 反馈与撤销**：支持流式文字预览，完整计划校验通过后才执行页面操作；服务返回普通 JSON 也可处理。最近一次阅读器页面操作可撤销，恢复之前的篇章、布局、字号和临时标注。原文或页面身份变化后不恢复过期操作；历史对话不重放操作。
4. **永久批注**：划选原文后点“保存划选批注”，或在就地讲解中保存。支持黄色、绿色、紫色及个人备注；可从“我的批注”打开或删除。重开与重启会恢复已保存高亮。批注同时记录正文摘要和重复引文序号；正文变化后保留批注内容但停止自动高亮。
5. **来源与当前页提问**：AI 回答展示实际加载的知识资料及原文定位卡片，可打开条目或对应篇章。它们是参考来源，不代表每个回答命题都已得到资料证明。知识库页可围绕当前条目提问；作文和翻译页的快捷提问会带入当前草稿，编辑草稿会取消旧上下文请求。
6. **知识点自测与复习**：内置自测先答后展开依据；无预置题目的资料使用复述规则与造句自测。可主动加入知识点复习，入口在复习页与首页到期提醒中；用户核对后选择不会、模糊、会用。可按需请求 AI 生成一题新的原创练习，先显示题目，答案隐藏。
7. **错题联动**：在答案解析下整理本题错因、证据与方法，关联真实知识条目并打开同类自测。复习页的错题复盘列表可回到对应篇章并聚焦题目。AI 错因建议只填入待确认表单，由用户核对后保存；未保存复盘离开页面时提醒。
8. **逐处修改**：批改问题具有准确原句和可替换英文时，可逐条采纳，并撤销最近一次采纳。只替换唯一匹配的原文片段；引文重复或已经修改时拒绝替换。旧批改缺少 replacement 时保留建议，供手动编辑。修改后原评分失效，可重新批改；问题可整理为薄弱点笔记。
9. **回收站**：删除个人笔记改为移入回收站，正文、标签、来源保留，可恢复；删除后的条目不进入普通检索、AI 资料加载或知识点复习队列。恢复后可继续使用原关联记录。当前不自动永久清空回收站。

作文同时显示英文词数和字符数，词数按英文/数字词块估计，不再把字符串长度当作词数。

## 数据与边界

- `electron/study.cjs` 增量建立 study_visit、reader_annotation、knowledge_review、knowledge_review_operation、mistake_note；聊天记录增加 sources，知识笔记增加 deleted_at。原始 SCHEMA 的必需字段集合保持不变，旧备份仍可检查与恢复。
- 新的访问记录、批注、复习评分、复盘和回收恢复使用主进程 persistTransaction。磁盘失败恢复内存快照，知识点评分携带操作身份防止重试重复调度。
- 知识点复习独立于词汇调度，不改原有词汇算法。不会约 10 分钟后再复习，模糊约 1 天，会用按成功次数逐步延长至最多 30 天。这是简单的初版安排，不宣称为个体最优间隔。
- 永久批注不会自动保存所有 AI 标注；必须由用户点击保存。撤销页面操作不删除永久批注，也不撤销用户作答。
- 流式解析位于 `electron/ai-stream.cjs`，处理跨块 UTF-8、逐行 SSE、完成标记、长度上限及截断/取消；不执行任何部分 JSON 计划。纯 JSON 响应沿用完整验证。
- 草稿、个人备注、知识笔记仅在用户主动调用对应 AI 功能时作为相关上下文发送给所配置服务；不将 API Key 放入提示词。AI 生成质量取决于用户模型，本地测试验证软件链路而非真实模型教学效果。

## 主要实现位置

- `src/views/HomeView.vue`：续学入口、真实最近访问、草稿入口。
- `src/components/ReaderAssistant.vue`：页面撤销、批注编辑、持久高亮恢复。
- `src/components/KnowledgePractice.vue`、`KnowledgeReview.vue`、`MistakeNote.vue`：自测、复习、复盘联动。
- `src/components/EssayRevisions.vue`、`src/utils/essay-revisions.js`：唯一引文替换及撤销。
- `scripts/regression-study.cjs`、`scripts/experience-check.mjs`：专项验证入口，已接入 test:experience 与 CI。
